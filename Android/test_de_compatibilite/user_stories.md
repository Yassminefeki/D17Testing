# User Stories — Test de compatibilité

Format requis:

- En tant que ... I want ... so that ...

Exemples (2–3 user stories pour démarrer):

1) En tant que utilisateur, I want the app to function on Android 10, 11 and 12 so that a wide base of devices is supported.

2) En tant que QA, I want UI layouts to adapt to different screen densities and orientations so that no UI overlaps occur.

3) En tant que utilisateur, I want the app to support small-screen and large-tablet layouts so that features are usable on tablets.

Précisions:
- Indiquer résolutions, densités d'écran, versions Android, fabricants prioritaires.
