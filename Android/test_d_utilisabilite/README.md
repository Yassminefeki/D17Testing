# Test d'utilisabilité

Objectif: Évaluer l'expérience utilisateur, la clarté des parcours et l'accessibilité.

Fichiers:
- `user_stories.md`
- `acceptance_criteria.md`

Exemple rapide:
- User story: "En tant que nouvel utilisateur, I want a clear onboarding so that I can set up my account easily." 

Instructions: documenter les hypothèses utilisateurs et méthodes (tests utilisateurs, heuristiques, KPIs).
