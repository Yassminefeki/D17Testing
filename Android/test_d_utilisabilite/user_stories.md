# User Stories — Test d'utilisabilité

Format requis:

- En tant que ... I want ... so that ...

Exemples (2–3 user stories pour démarrer):

1) En tant que nouvel utilisateur, I want a guided onboarding so that I can complete setup without help.

2) En tant que utilisateur, I want primary actions to be reachable within two taps so that I can perform tasks quickly.

3) En tant que personne avec déficience visuelle, I want proper screen-reader labels and high-contrast themes so that the app is accessible.

Précisions:
- Indiquer métriques UX (taux de réussite, temps pour compléter, satisfaction).
