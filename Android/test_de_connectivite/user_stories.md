# User Stories — Test de connectivité

Format requis:

- En tant que ... I want ... so that ...

Exemples (2–3 user stories pour démarrer):

1) En tant que utilisateur, I want the app to queue actions while offline so that they are synced when connection is restored.

2) En tant que utilisateur, I want the app to show clear offline status and retry options so that I know whether actions are pending.

3) En tant que ingénieur, I want the app to handle intermittent packet loss with graceful retries so that data integrity is preserved.

Précisions:
- Décrire conditions réseau (offline, high-latency, packet loss).
