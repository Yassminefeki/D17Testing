# Test de connectivité

Objectif: Vérifier le comportement aux changements/limitations de connectivité (offline, réseau instable).

Fichiers:
- `user_stories.md`
- `acceptance_criteria.md`

Exemple rapide:
- User story: "En tant que utilisateur, I want the app to gracefully handle offline mode so that I can continue some tasks without network." 

Instructions: préciser comportements en offline, en file d'attente, et stratégie de retry/backoff.
