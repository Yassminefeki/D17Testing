# User Stories — Test de sécurité

Format requis pour chaque user story:

- En tant que ... I want ... so that ...

Exemples (2–3 user stories pour démarrer):

1) En tant que utilisateur standard, I want to enable multi-factor authentication so that my account is protected against credential compromise.

2) En tant que administrateur, I want to enforce password complexity and rotation policies so that corporate accounts remain secure.

3) En tant que utilisateur, I want the app to lock after 5 failed login attempts so that brute-force attacks are mitigated.

Notes pour l'affinage:
- Précisez le rôle (admin, user, guest).
- Détaillez le contexte (appareil, réseau public/privé).
- Ajoutez des scénarios négatifs si pertinent.
