# User Stories — Test d'intégration

Format requis:

- En tant que ... I want ... so that ...

Exemples (2–3 user stories pour démarrer):

1) En tant que utilisateur, I want profile updates to be persisted server-side so that changes appear on another device.

2) En tant que développeur, I want client calls to the profile API to return consistent data under concurrent updates so that no conflicting states occur.

3) En tant que QA, I want backup/fallback behavior when external auth service is unavailable so that login attempts fail gracefully.

Précisions:
- Indiquez les endpoints, payloads, et préconditions (utilisateur connecté, token valide).
