# Test de sécurité

Objectif: Définir les cas de test de sécurité pour l'application Android.

Fichiers dans ce dossier:
- `user_stories.md` : modèles et espaces pour rédiger les user stories liées à la sécurité.
- `acceptance_criteria.md` : critères d'acceptation exprimés en Given / When / Then.

Exemple rapide:
- User story: "En tant que utilisateur, je veux m'authentifier avec MFA afin que mes données soient protégées." 
- Acceptance Criteria: Voir `acceptance_criteria.md` pour format.

Instructions:
- Renseignez une user story par section dans `user_stories.md` en respectant la structure demandée.
- Ajoutez les critères d'acceptation correspondants dans `acceptance_criteria.md`.
